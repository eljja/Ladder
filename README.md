## 📖 프로젝트 소개 (Overview)

기존 2차원 평면 사다리타기는 **양쪽 끝 기둥(0번 기둥과 N-1번 기둥)이 단절**되어 있어, 가장자리 참가자와 중앙 참가자의 이동 확률과 경로 분기 수가 불공평하게 분배되는 구조적 한계를 지니고 있었습니다.

**Cylinder Ladder 3D**는 사다리 기둥들을 **3D 원통(Cylinder) 둘레에 원형으로 배치**하여, 0번 기둥과 마지막 기둥이 자연스럽게 맞물려 돌아가는 **무경계(Zero-Boundary) 360도 사다리 구조**를 구현했습니다.

```
       [2D 기존 사다리]                [3D 원통형 사다리]
     0   1   2   3   N-1               (0) ─── (1)
     │   │   │   │    │               /           \
     ├───┤   │   ├───┤              (N-1)         (2)
     │   ├───┤   │    │               \           /
     (양 끝 단절: 불공평)                 (4) ─── (3)
                                 (360도 환형 연결: 100% 공평)
```

## ✨ 주요 기능 (Key Features)

### 1. 🔄 100% 공평한 360도 원통 구조
- 모든 참가자 기둥이 동일한 간격과 좌우 연결 기회를 가집니다.
- 양쪽 끝의 개념이 사라져 어떤 기둥을 선택하든 수학적으로 완벽하게 대칭적이고 공평합니다.

### 2. 🚀 2가지 플레이 모드
- **전체 동시 출발 모드 (Simultaneous Mode)**:
  - 모든 참가자의 마블 구슬이 상단 출발선에서 일제히 굴러 떨어지며 실시간 경로를 경주합니다.
- **개별 터치 모드 (Individual Touch Mode)**:
  - 상단에 위치한 참가자 구슬을 직접 클릭하거나 터치하여 원하는 구슬만 하나씩 차례대로 출발시킬 수 있습니다.
  - 모든 참가자가 끝까지 도착한 후에만 최종 추첨 결과가 집계되어 팝업됩니다.

### 3. ✍️ 자유로운 인터랙티브 사다리 그리기 & 지능형 터치
- **양방향 드래그 연결**: 기둥을 마우스/터치로 잡고 좌측 또는 우측으로 드래그하여 원하는 방향으로 다리를 자유롭게 생성합니다.
- **수평 및 대각선 다리 지원**: 단순 가로선뿐만 아니라 위아래 기울기를 가진 대각선 사다리도 설치 가능합니다.
- **와이드 히트 프록시 & 로컬 좌표 변환**:
  - 기둥 주변 약 25px 반경의 넉넉한 터치 히트 박스(`TubeGeometry`)와 실린더 틸트 각도를 보정하는 `worldToLocal` 변환을 적용하여 모바일과 PC 모두에서 빗맞춤 없이 100% 정확하게 클릭 및 드래그가 인식됩니다.
- **실시간 설치 유효성 피드백**:
  - 드래그 도중 설치 가능한 위치는 **골드 🟡**, 기존 다리와 겹치는 충돌 위치는 **네온 레드 🔴**로 표시됩니다.
- **원클릭 삭제**: 이미 생성된 다리를 탭/클릭하면 즉시 제거됩니다.
- **Bijective(1:1 전단사) 무작위 사다리 생성**:
  - 슬라이더로 밀도를 조절하여 모든 참가자가 서로 다른 목적지에 겹치지 않고 정확히 1:1로 도달하는 공평한 랜덤 사다리를 원클릭으로 생성합니다.

### 4. 🎥 다이내믹 3D 카메라 & 📐 원근/하단 크기 조절
- **스마트 자전 추적 (Spin Tracking)**:
  - 레이스 진행 시 1등 마블(또는 현재 이동 중인 유일한 마블)을 향해 원통이 부드럽게 자전하며 중앙에 보여줍니다.
  - 카메라 및 원통 회전 시 마블 속도를 0.5배속으로 자연스럽게 감속하여 어지러움 없이 안정적인 관람을 보장합니다.
- **🔝 완전 수직 탑뷰 (Top-Down View)**:
  - 하단 및 사이드바의 **`[🔝 탑뷰]`** 버튼을 누르면 위에서 룰렛처럼 내려다보는 수직 탑뷰로 전환됩니다.
- **📐 원근 / 하단 크기 조절 슬라이더 (`0.20x` ~ `1.00x`)**:
  - 탑뷰 및 3D 뷰에서 하단이 좁아지는 원근감의 정도를 자유롭게 조절할 수 있습니다.
  - `1.00x (기본값)`: 완전한 원통형 구조
  - `0.20x ~ 0.95x`: 아래로 갈수록 좁아지는 원뿔형(Cone) 구조로 원근감과 깊이감을 극대화
  - 슬라이더 조절 시 실린더 표면, 기둥 경사각, 사다리 다리, 골대 위치, 마블의 롤링 곡면이 실시간으로 부드럽게 재계산되어 동기화됩니다.
- **자유로운 3D 궤도 제어 & 핀치 줌**:
  - 마우스 드래그로 360도 자전 및 상하 틸트 조절이 가능합니다.
  - 마우스 휠 및 모바일 터치 두 손가락 **핀치 줌(Pinch-to-Zoom)**을 지원합니다.
  - 상단 헤더와 하단 컨트롤 바에 가려지지 않도록 최적의 줌 여백을 유지합니다.

### 5. 🎵 아케이드 사운드 & 유튜브 배경음악
- **유튜브 사다리 BGM**: 게임 진입 후 첫 조작 시 경쾌한 전용 BGM이 자동 재생되며, 사이드바 버튼으로 On/Off가 가능합니다.
- **Web Audio API 인터랙티브 효과음**: 마블의 3D 롤링음, 다리 통과음, 다리 추가/삭제음, 폭죽 팡파르 효과음을 탑재했습니다.

### 6. 👥 프리셋 관리 및 서바이벌 모드
- **다양한 기본 프리셋**: 점심 쏘기, 커피 내기, 당번 뽑기, 1등 뽑기 등.
- **커스텀 프리셋 저장**: 참가자 명단과 벌칙 목록을 브라우저 `localStorage`에 저장하고 언제든 불러올 수 있습니다.
- **서바이벌 모드 (당첨자 제외하고 다음 판)**: 추첨 결과에서 당첨자를 제외하고 바로 다음 라운드를 연속 진행할 수 있습니다.
- **결과 복사**: 추첨 결과를 한 번의 클릭으로 클립보드에 깔끔한 텍스트로 복사할 수 있습니다.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 기술 / 라이브러리 | 용도 |
|:---:|:---:|:---|
| **Core** | **TypeScript 5.6** | 정적 타입 검증 및 원통 사다리 수학 모델링 |
| **3D Engine** | **Three.js 0.170** | WebGL 원통/원뿔 지오메트리, 동적 레일, 마블 물리 롤링, 2D 스프라이트 |
| **Bundler** | **Vite 6.0** | 초고속 HMR 및 최적화된 프로덕션 빌드 |
| **Styling** | **Sass (SCSS)** | 네온 사이버펑크 글래스모피즘(Glassmorphism) 반응형 UI |
| **Effects** | **Canvas-Confetti** | 추첨 결과 축하 폭죽 파티클 |
| **Audio** | **Web Audio API & YouTube API** | 배경 음악 및 인터랙티브 효과음 합성 |
| **Linter** | **Biome** | 빠른 코드 포맷팅 및 린팅 |

## 📁 프로젝트 구조 (Directory Structure)

```
Ladder/
├── index.html                 # 메인 엔트리 HTML 및 UI 마크업
├── package.json               # 프로젝트 의존성 및 스크립트
├── vite.config.ts             # Vite 빌드 및 베이스 경로 설정
├── tsconfig.json              # TypeScript 컴파일러 옵션
├── src/
│   ├── main.ts                # 앱 진입점 및 렌더 루프
│   ├── core/
│   │   ├── CylinderLadder.ts  # 원통/원뿔 사다리 기하 및 브릿지 데이터 모델 (테이퍼 계산 포함)
│   │   ├── LadderSolver.ts    # 경로 해석, 사이클 방지 및 전단사(Bijective) 검증
│   │   ├── MarbleRunner.ts    # 마블 물리 이동, 다리 분기 판정 및 이벤트 디스패처
│   │   ├── SoundManager.ts    # Web Audio API 사운드 합성 및 효과음 관리
│   │   ├── BgmManager.ts      # 유튜브 IFrame 사다리 BGM 매니저
│   │   └── ConfettiManager.ts # 축하 폭죽 효과 매니저
│   ├── render/
│   │   ├── CylinderScene.ts   # Three.js 씬, 카메라 조작, 레이캐스팅, 동적 원뿔 곡면 렌더링
│   │   └── MarbleMesh.ts      # 3D 마블 구체 및 2D 캔버스 이름표 스프라이트
│   ├── ui/
│   │   └── LadderUI.ts        # DOM UI 바인딩, 프리셋 관리, 슬라이더 이벤트 및 결과 모달
│   └── styles/
│       └── style.scss         # 전체 UI 및 반응형 네온 글래스 스타일
```

## 🚀 시작하기 (Getting Started)

### 전제 조건
- Node.js (v18 이상 권장)
- npm

### 1. 저장소 복제
```bash
git clone https://github.com/eljja/Ladder.git
cd Ladder
```

### 2. 패키지 설치
```bash
npm install
```

### 3. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속하여 즉시 테스트할 수 있습니다.

### 4. 프로덕션 빌드
```bash
npm run build
```
빌드된 정적 파일은 `dist/` 디렉터리에 생성됩니다.

## 🎮 플레이 조작법 (Controls)

| 동작 | 조작 방법 |
|---|---|
| **다리 그리기** | 기둥 표면을 클릭/터치한 상태로 좌/우 인접 기둥으로 드래그 (골드: 설치 가능 / 레드: 충돌) |
| **다리 삭제** | 배치되어 있는 가로/대각선 다리 클릭/터치 |
| **3D 시점 회전** | 빈 배경을 클릭/터치하고 상하좌우 드래그 |
| **줌 인 / 줌 아웃** | 마우스 휠 스크롤 또는 모바일 핀치 줌 |
| **개별 구슬 출발** | [🎯 개별 터치 모드] 상태에서 상단의 구슬 직접 클릭 |
| **탑뷰 전환** | [🔝 탑뷰] 버튼 클릭 |
| **원근 / 하단 크기 조절** | 사이드바의 [📐 원근 / 하단 크기 조절] 슬라이더 조절 (0.2x ~ 1.0x) |
| **배경음악 On/Off** | 사이드바의 [🎵 BGM ON/OFF] 버튼 클릭 |
