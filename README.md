## 📖 프로젝트 소개 (Overview)

기존 2차원 평면 사다리타기는 **양쪽 끝 기둥(0번 기둥과 N-1번 기둥)이 단절**되어 있어, 가장자리 참가자와 중앙 참가자의 이동 확률과 경로 분기 수가 불공평하게 분배되는 구조적 한계를 지니고 있었습니다.

**Cylinder Ladder 3D**는 사다리 기둥들을 **3D 원통(Cylinder) 둘레에 원형으로 배치**하여, 0번 기둥과 마지막 기둥이 자연스럽게 맞물려 돌아가는 **무경계(Zero-Boundary) 360도 사다리 구조**를 구현했습니다.

```
       [2D 기존 사다리]                [3D 원통형 사다리]
     0   1   2   3   N-1               (0) ─── (1)
     │   │   │   │    │               /           \
     ├───┤   │   ├───┤              (N-1)         (2)
     │   ├───┤   │    │               \           /
     (양 끝 단절: 불공평)                 (4) ─── (3)
                                 (360도 환형 연결: 100% 공평)
```

## ✨ 주요 기능 (Key Features)

### 1. 🔄 100% 공평한 360도 원통 구조
- 모든 참가자 기둥이 동일한 간격과 좌우 연결 기회를 가집니다.
- 양쪽 끝의 개념이 사라져 어떤 기둥을 선택하든 수학적으로 완벽하게 대칭적이고 공평합니다.

### 2. 🧑‍💼 마블 얼굴 사진(증명사진) 커스텀 매핑 & 3D 구르기 회전 연출
- **원클릭 클립보드 붙여넣기 (`Ctrl+V`)**:
  - 마블을 클릭해 선택한 후, 외부에서 복사한 사진을 `Ctrl+V`로 붙여넣으면 즉시 구슬에 원형으로 적용됩니다.
  - 인물 중심 증명사진에 맞춘 **중앙 정사각형 자동 크롭 & 160x160 원형 아바타**로 압축되어 깔끔하게 매핑됩니다.
- **3D 쿼터니언 구르기(Rolling Physics) 회전 연출**:
  - 마블이 사다리를 타고 좌/우/아래로 이동할 때, 이동 변위 $\Delta \vec{p}$에 따라 **실제 물리 구르기 회전축 $\vec{\omega} = \Delta \vec{p} \times \vec{r}$ 기반의 3D 쿼터니언 회전**이 실시간 적용되어 **얼굴도 구슬과 함께 생생하게 굴러갑니다!**
- **이름별 영구 저장 (`localStorage`)**:
  - `localStorage`(`marble_face_avatars`)에 참가자 이름과 사진이 영구 보존되어 다음 접속 시에도 동일한 이름에 자동으로 사진이 유지됩니다.
- **사진 삭제**: 마블을 선택하고 `Delete` 또는 `Backspace` 키를 누르면 얼굴 사진이 즉시 삭제됩니다.

### 3. 🚀 2가지 플레이 모드 & 마블 선택 분리
- **개별 터치 모드 분리**:
  - **개별 터치 모드 OFF**: 상단 마블을 클릭하면 출발하지 않고 **마블이 선택(골드 펄스 링 표시)**되어 사진을 붙여넣거나 삭제할 수 있습니다.
  - **개별 터치 모드 ON**: 상단 구슬을 클릭하면 해당 참가자의 구슬만 사다리를 타고 차례대로 출발합니다.
- **전체 동시 출발 모드 (Simultaneous Mode)**:
  - [🚀 전체 동시 출발] 버튼을 누르면 모든 참가자의 구슬이 상단에서 일제히 굴러떨어지며 레이스를 펼칩니다.

### 4. ✍️ 자유로운 인터랙티브 사다리 그리기 & 지능형 터치
- **양방향 드래그 연결**: 기둥을 마우스/터치로 잡고 좌측 또는 우측으로 드래그하여 원하는 방향으로 다리를 자유롭게 생성합니다.
- **수평 및 대각선 다리 지원**: 단순 가로선뿐만 아니라 위아래 기울기를 가진 대각선 사다리도 설치 가능합니다.
- **실시간 설치 피드백**: 드래그 중 설치 가능 위치는 **골드 🟡**, 충돌 위치는 **네온 레드 🔴**로 표시됩니다.
- **원클릭 삭제**: 생성된 다리를 클릭/탭하면 즉시 제거됩니다.
- **Bijective(1:1 전단사) 무작위 사다리 생성**: 슬라이더로 밀도를 조절하여 모든 참가자가 서로 다른 목적지에 겹치지 않고 도달하는 공평한 랜덤 사다리를 원클릭으로 생성합니다.

### 5. 🔄 당첨자 제외 서바이벌 모드 (구조적 무결성 보장)
- 추첨 후 [당첨자 제외하고 다음 판] 버튼을 누르면 당첨된 참가자를 제외하고 사다리가 자동으로 재구성됩니다.
- **사다리 연결 보존 알고리즘**: 특정 기둥이 제외되더라도 인접 가로선이 모두 소실되어 사다리가 단절되는 현상을 방지하고, 남은 기둥들이 견고하게 연결되도록 사다리 구조를 재연결합니다.
- **4,000회 시뮬레이션 무오류 검증**: 대규모 무작위 참가자 수 및 사다리 밀도 조합에서 4,000회 전수 시뮬레이션을 수행하여 결함 제로의 안정성을 입증했습니다.

### 6. 🎥 다이내믹 3D 카메라 & 시각 최적화
- **스마트 자전 추적 (Spin Tracking)**: 레이스 진행 시 선두 마블을 향해 원통이 부드럽게 자전하며 최적의 앵글을 유지합니다.
- **이름표 가림 방지 (r축 오프셋)**: 마블의 궤적과 이름표가 사다리 수직선에 가려지지 않도록 법선(반경) 방향으로 미세 오프셋을 적용해 가독성을 극대화했습니다.
- **🔝 완전 수직 탑뷰**: 룰렛처럼 위에서 내려다보는 수직 탑뷰를 지원합니다.
- **📐 원근 / 하단 크기 조절 슬라이더 (`0.20x` ~ `1.80x`)**: 원통형(1.0x), 원뿔형(0.2x~0.95x), 역원뿔형(1.05x~1.8x)으로 구조를 자유롭게 변형할 수 있습니다.
- **🔒 카메라 고정 모드**: 원통 회전 및 상하 이동을 완전히 멈추고 고정된 시점에서 관람할 수 있습니다.

### 7. 🎵 아케이드 사운드 & 유튜브 BGM
- **YouTube 배경음악**: 첫 터치 시 신나는 사다리 BGM 자동 재생 (사이드바에서 On/Off 가능).
- **Web Audio API 효과음**: 마블의 3D 롤링음, 다리 통과음, 다리 추가/삭제음, 폭죽 팡파르 효과음 탑재.

## 🎮 플레이 조작법 (Controls)

| 동작 | 조작 방법 | 설명 |
|---|---|---|
| **마블 선택** | 상단 마블 구슬 클릭 (개별터치 OFF 시) | 골드 펄스 링 표시, 사진 등록/삭제 대기 |
| **얼굴 사진 등록** | 마블 선택 상태에서 **`Ctrl+V`** | 클립보드 이미지를 구슬의 얼굴로 등록 |
| **얼굴 사진 삭제** | 마블 선택 상태에서 **`Delete` / `Backspace`** | 등록된 얼굴 사진 제거 |
| **개별 구슬 출발** | 상단 마블 구슬 클릭 (개별터치 ON 시) | 선택한 구슬 하나만 사다리를 타고 출발 |
| **다리 그리기** | 기둥 표면을 클릭/터치한 상태로 인접 기둥으로 드래그 | 골드: 설치 가능 / 레드: 충돌 |
| **다리 삭제** | 배치되어 있는 가로/대각선 다리 클릭/터치 | 해당 다리 즉시 제거 |
| **3D 시점 회전** | 빈 배경을 클릭/터치하고 상하좌우 드래그 | 자유로운 360도 궤도 회전 |
| **줌 인 / 줌 아웃** | 마우스 휠 스크롤 또는 모바일 핀치 줌 | 부드러운 거리 조절 |
| **탑뷰 전환** | [🔝 탑뷰] 버튼 클릭 | 상단 수직 탑뷰 토글 |
| **카메라 고정** | [🔒 카메라 고정] 버튼 클릭 | 자동 회전/추적 일시 정지 및 고정 |

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 기술 / 라이브러리 | 용도 |
|:---:|:---:|:---|
| **Core** | **TypeScript 5.6** | 정적 타입 검증 및 3D 원통 기하학 수학 모델링 |
| **3D Engine** | **Three.js 0.170** | WebGL 실린더/콘 지오메트리, 마블 물리 롤링 쿼터니언, 캔버스 텍스처 |
| **Bundler** | **Vite 6.0** | 초고속 HMR 및 최적화된 프로덕션 빌드 |
| **Styling** | **Sass (SCSS)** | 네온 사이버펑크 글래스모피즘(Glassmorphism) 반응형 UI |
| **Effects** | **Canvas-Confetti** | 추첨 결과 축하 폭죽 파티클 |
| **Audio** | **Web Audio API & YouTube API** | 배경 음악 및 인터랙티브 효과음 합성 |
| **Linter** | **Biome** | 빠른 코드 포맷팅 및 린팅 |

## 🚀 시작하기 (Getting Started)

### 전제 조건
- Node.js (v18 이상 권장)
- npm

### 1. 저장소 복제
```bash
git clone https://github.com/eljja/Ladder.git
cd Ladder
```

### 2. 패키지 설치
```bash
npm install
```

### 3. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속하여 즉시 테스트할 수 있습니다.

### 4. 프로덕션 빌드
```bash
npm run build
```
빌드된 정적 파일은 `dist/` 디렉터리에 생성됩니다.
